# LinguaFlow — словарь английского

Фронтенд: React 19 + Vite + TypeScript + TailwindCSS v4. Хранит слова и перевод, показывает дату создания и обновления.

## Возможности
- Слова и выражения: таблица (слово, перевод, пример, создано), поиск, пагинация
- Добавление и редактирование через модальное окно; повторы отклоняются тостом (проверка + `409` с сервера)
- Значение открывается в модальном окне, не разъезжая таблицу
- Правила грамматики по уровням A1–C2 и общие: таблицы, примеры, разбор ошибок
- Сворачиваемый сайдбар (на десктопе — узкая полоса с иконками)

## Запуск

```powershell
cd C:\Learn\english-frontend
npm install
npm run dev
# -> http://localhost:5173
```

Бэкенд должен работать на `http://localhost:8080` — proxy настроен в `vite.config.ts`.

## Сборка

```powershell
npm run build
npm run preview
```
